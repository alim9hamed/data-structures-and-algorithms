# Data Structures and Algorithms in Python

Python implementations and exercises created while studying data structures
and algorithms.

The repository includes arrays, linked lists, stacks, queues, hash tables,
binary search trees, heaps, priority queues, sorting algorithms, and graph
search and traversal.

See [STUDY_GUIDE.md](STUDY_GUIDE.md) for topic explanations, complexity notes,
connections to the *Grokking* books, and a LinkedIn post draft.

## Run the graph tests

```bash
python -m unittest test_graph.py
```

These are learning exercises and are not intended as a production-ready library.
